Gestão de Matéria-Prima

Sistema de controle de estoque com código de barras e reconhecimento facial para otimizar a gestão de matérias-primas da empresa Amemiya.

Sobre o Projeto

Solução Completa

O BARCODER'S foi desenvolvido especificamente para a empresa Amemiya, oferecendo uma solução robusta e eficiente para o controle de estoque de matérias-primas.

  • Controle em tempo real
  • Interface intuitiva e segura
  • Relatórios de Matéria-Prima

Sistema em Implantação

Solução completa em produção na Amemiya

Principais Funcionalidades

Código de Barras

Leitura e geração automática de códigos para identificação rápida de produtos e lotes.

Controle de Estoque

Monitoramento em tempo real com rastreabilidade completa do ciclo do material.

Relatórios Gerenciais

Dashboard com KPIs de consumo, composição de estoque e movimentações.

Controle de Qualidade

Processo de identificação de material antes do envio para a produção.

Tecnologias Utilizadas

Node.js

Express.js

MySQL

Tailwind CSS
